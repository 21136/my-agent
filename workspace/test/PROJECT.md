# Music Dreamer 悦享音乐 · 项目章程

## 目标
- 面向普通用户提供最佳音乐体验，同时降低音乐创作者发布门槛，实现“创作者随时分享，用户随时收听”。
- 基于 Spring Cloud Alibaba 微服务 + Spring Boot + Vue 构建可演进的音乐流媒体系统第一版。

## 用户与场景
- 普通用户：注册登录、搜索/播放歌曲、接收推荐、收藏歌曲与歌单、查看收听历史、接收通知。
- 音乐创作者：低门槛申请成为歌手，上传音频/封面/歌词并发布歌曲，管理自己的作品。
- 后台管理员：审核与管理用户、歌手、歌曲，处理违规内容。

## 范围摘要
- 第一轮范围见 `SCOPE.md`；模块边界见 `TECH-DESIGN.md`；执行计划见 `TASKS.md`；验证矩阵见 `VERIFY.md`。
- 所有验收项均以 `VERIFY.md` 的证据为准，未通过验证不得进入发布。

## 非目标
- 不实现实时音视频直播、社交评论/弹幕、版权交易、高保真无损多版本、移动端原生 App。
- 不包含商业化支付、广告投放、智能硬件接入。
