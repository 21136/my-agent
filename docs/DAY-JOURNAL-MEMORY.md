## 0. 一句话

表面上只有一个会话界面；底下用 **按天日记目录** 管时间线，用 **按项目、按天的会话库** 管进项目时的完整片段，用 **久远记忆** 管跨天仍值得留的硬事实。三套分工，同一事实不双写。

---

## 1. 表面：一个会话界面

用户始终在同一聊天窗说话；不强制先选「会话 / 项目」入口。

底层仍可按会话 / 项目拆上下文与权限（只聊 vs 动手、项目 scope），但那是运行时路由，不是用户要切换的第二套「记忆产品」。

---

## 2. 目录层：按天日记（Day journal directory）

按 **自然日** 一条（或一天一条可展开的目录项）。

### 2.1 表面信息（目录上能看到的）

| 字段 | 内容 | 注意 |
|------|------|------|
| 日期 | 哪一天 | 用户时区（Asia/Shanghai） |
| 聊了什么 | 当天闲聊 / 总览的 **压缩摘要** | 短，可扫 |
| 动过哪些项目 | 项目 **名 / id** 列表 | **只写项目身份，不写改了什么代码** |

目录层禁止贴 diff、文件路径清单或代码级变更说明。

### 2.2 写入时机（建议，未实现）

- **不要**实时双写目录与详情（易抖、易脏）。
- 优先在 **按天收尾** 或 **context 压缩（compact）** 时生成 / 更新目录条。

---

## 3. 某天详情（Day detail）

点进某一天后：

### 3.1 普通对话

- 闲聊时段：**保留**原文，或仅做轻量压缩（仍可回看对话感）。

### 3.2 进项目时段

当这一天里进入过某个项目工作时，该时段在「某天详情」里 **不堆完整项目会话**，只留下：

1. **短压缩提示**：几句话说明「这个项目里大概改了 / 做了什么」——**不到代码层面**（无大段 diff、无逐文件清单）。
2. **稳定链接**：点进去能通到该时段的具体会话内容（见 §4）。

### 3.3 项目提示模板（建议，未实现）

固定三句左右，例如：

1. 做了什么（结果向）
2. 未完成 / 下一步
3. 可点开看完整片段（链接）

避免模型把提示写成小作文。

---

## 4. 项目会话库（Project session store）

链接指向的「具体会话内容」：

- **按项目**保存；
- 项目内再 **按天**归档。

也就是说：完整进项目对话不堆在「全局某天详情」里，而在 `项目 → 某天` 下；日记详情只留短提示 + 链接。

### 4.1 链接稳定性（建议，未实现）

链接应指向稳定坐标，例如：

`project_id + date + segment_id`

**不要**依赖会滚动的消息行号或可变 UI 索引。

### 4.2 落地切片（建议顺序，未实现）

| 切片 | 内容 | 状态 |
|------|------|------|
| **第一刀** | 按天目录 + 进项目时段的短提示与链接（链接可先落到现有 thread / 片段 id） | 草案 |
| **随后** | 完整的「按项目、按天」会话库与浏览面 | 草案 · 后做 |

---

## 5. 与久远记忆（Letta / MemGPT）的分工

已选久远记忆形态（与现网 MEMORY 三件套中的「久远」一致、并向 Letta/MemGPT 收紧）：

- **核心**：system 里只留很小的 id + summary 索引；
- **正文**：按需 `read_file`（或等价读正文工具）。

| 机制 | 管什么 | 不管什么 |
|------|--------|----------|
| **按天日记** | 时间线：哪天聊了啥、动过哪些项目；进项目时段的短提示与链接 | 跨天仍成立的偏好、约定、硬事实百科 |
| **久远记忆** | 跨天仍值得留的硬事实（偏好、约定、长期背景） | 「哪天改过哪个项目」的流水账 |

### 5.1 不打架规则

- 同一事实 **只升格一次**：该进久远的进久远；日记里可 **链过去**，不两处各写一篇长文。
- 日记是 **何时 / 哪个项目**；久远是 **长期仍为真**。

### 5.2 查找怎么走

| 用户想查 | 优先走 |
|----------|--------|
| 哪天聊过、某项目那天大概做了啥 | **按天日记**（再经链接进项目按天库） |
| 长期偏好、约定、人设级事实 | **久远记忆** |

典型路径：先日记定位时间与项目 → 需要硬事实再读久远。

## 6. 概念图（与用户对齐过的理解）

```text
[ 一个会话界面 ]
        |
        v
[ 目录 · 按天 ]
  · 日期
  · 聊了什么（压缩）
  · 动过哪些项目（仅名/id）
        |
        v
[ 某天详情 ]
  · 普通对话：保留（或轻压缩）
  · 进项目时段：几句「项目里改了什么」的压缩提示（非代码）
                 + 稳定链接
        |
        v
[ 项目会话库 · 按项目 · 再按天 ]
  · 该项目当天的完整会话片段

另路（不替代日记）：
[ 久远记忆 · 小索引 + 按需正文 ]  <- 跨天硬事实
```
