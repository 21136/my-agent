# 执行可靠性

本专题的当前行为以 `agent-core/exec_reliability.py`、`agent-core/tools/executor.py` 与对应测试为准。可靠性保护包括工具失败结果处理、重复失败熔断、执行后置条件及有限预算；具体开关和值应从当前实现读取。

失败类别、错误摘要或状态面板是诊断信号，不是自动修复授权。模型/子代理可分析错误，但修改文件、运行命令及对外操作仍通过 Executor 的路径、风险和确认策略。验证失败不得报告成功；未运行的命令不得计为通过。

历史 Phase、Progress Gate、TASKS 勾选和 runaway 阈值不构成当前普通项目可靠性契约。旧项目/测试 fixture 中出现这些名称不意味着该旧流程仍是产品入口。
