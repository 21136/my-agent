# 项目管理的源码范围选择（工程环节）

sandbox 的「壳开发预览 → 只读源码审查」增加相邻的逐路径选择区。先读取当前审查，再逐项声明本次准备交付的 sandbox 路径，点击「核验所选范围（不合入）」；项目使用宿主确定的实际根目录重新采集审查，与显示摘要一致后生成范围提案。

这不是另外一条手工合并路径：不运行 add/commit/stash/merge/reset/clean/push，不复制到稳定区，也不替换 URL。**提案不会连接旧的“一键合入”接口，不能用它表示已经合入或已经得到完整原生同意。** 稳定主壳不会因编辑 sandbox 自动更新。

## 逐路径选择的含义

- 所有 sandbox 项默认未选择，没有“全部属于本任务”按钮。未选路径完整列在排除清单，并保持在 sandbox，不推定已审核归属。
- 搜索是字面路径搜索，显示每页25项；只影响可见行，不改变已选范围。完整路径、sandbox 工作 SHA256、stable 对应清单及 HEAD/index/工作状态均可核对。
- 选择仅为**归属声明**，不证明是谁修改、来源可信、依赖完整或可交付。相同原始字节不证明暂存/模式/任务归属相同。
- 全部稳定区允许源码条目和原始 index 身份作为**保留要求**绑定进提案，并非保留操作已成功的回执。所选路径与 stable 任何已有本地/暂存/模式/缺失状态相交，均继续阻断，不选择 ours/theirs。
- 清单没有对应 stable 条目不表示文件不存在；这种缺失、来源元数据不足、两区大小写别名另列阻断，不能自动当作新增文件可安全落地。
- 所有历史/保护/完整清点阻断原样保留，不因为缩小选择范围或字节相同而消失。

## 可信边界

新增 `proposeManagedSourceSelection(request)` 只接受固定的 format/mode、完整 reviewDigest 和受限 selectedPaths。最多2048项，每项512个UTF-8字节，整个请求256KiB；额外字段、重复/大小写别名、越界、受保护路径和空选择均拒绝。渲染器不能提交根目录、报告、哈希、blockers或确认材料。

可信主页面和非fixture检查在所有路径解析/源读取前执行；异步解析、捕获结束后再次核对发送者。宿主重新确认固定关联工作区布局并读取真实审查，摘要漂移则要求重读。同步纯计划器校验报告及清单自摘要、基线绑定，生成完整 proposal_digest。摘要仅用于完整性/变更绑定，不是用户身份或同意凭证。

网页环境禁用核验，没有网络/Git兜底。组件重读、报错或清空会移除旧范围；改选会清除原提案。异步响应仅能填入它发出时的同一报告和同一选择状态，不能复活旧提案。

提案一直包含 `execution=false`、`readyForMerge=false`、`readyForLaunch=false`、`checkpointCreated=false`、`nativeConsent=false`。这是可信宿主的**只读工程接口**，没有执行/检查点/激活权限。测试中的本机HTTP组件传输不属于生产网页接口，也不证明 Electron 原生IPC验收。

## 本轮没有完成的工作

选定源码的内容检查点机制见 `MANAGED-SOURCE-CHECKPOINT.md`；它固定原始字节/模式，不是Git提交或可执行合入事务包，也不会清除上述阻断。仍需脏 stable 的安全保留合入、完整 AdoptionPlan 原生精确范围确认、操作态命名空间与可信上下文、实际合入及合并后重建封存、所有写路径 fencing/空库初始化/激活与恢复/LKG。现有项目命名空间仍保持 prepared_empty，未写入提案或放宽空布局。

安全私有 provider 适配与明确费用预算也仍独立缺失；真实项目模型只允许 `0x567-flash`，本轮没有调用模型、读取私有配置或访问/迁移旧聊天。

## 存储

本接口只处理路径/哈希/状态元数据，不复制依赖、源码树、运行时或建立新Git仓库，也不清理既有夹具/备份。提案当前只返回内存和界面，不在真实运行命名空间自动持久化。验收记录的逻辑字节与按F:分配单元估算值仅说明本轮资料，不代表双版本总占用或正式发布预算。
