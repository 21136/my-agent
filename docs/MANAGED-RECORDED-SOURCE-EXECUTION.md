# 已记录源码执行：受限工程接口

本页描述 `managed-clean-source-adapter.mjs` 和 `managed-source-package.mjs` 的工程边界，不替代 E1 正式采用链，也不是用户操作指南。这里的“完整计划包”仅指源码合并子计划及其全部输入；它不是包含发布、数据、租约与激活步骤的完整 E1 AdoptionPlan。

## 本轮补什么

旧协调器只保存摘要和合并回执，需要可信调用方提供执行适配器。本轮增加：

1. 对**已提交、完全允许范围内、无属性转换的干净源码**做只读完整清点，生成包含两边文件哈希、Git 身份、全部 ahead 提交路径和实际交付路径的审查包。
2. 将完整审查包、由它生成的合并计划及精确摘要确认，排他保存到既有调用者所有的操作目录。文件同步完成之后，才能调用记录式执行器。
3. 记录式执行器重读核验材料，创建受限适配器，交给现有单次写前日志协调器。项目代码执行一次真实 Git no-ff 合并，并核对实际提交、父提交、结果树、路径哈希与保留状态。

所有工程 API 都只供可信宿主进程调用。没有网页/插件回调入口，没有新增 CLI/IPC 的真实执行按钮，也没有把 JSON 里的确认当成“来自原生用户界面”的证明。

## 为什么当前工程仍不能直接合入

受限适配器只处理 sandbox 恰在 stable/.worktrees/sandbox、两者共用 Git common-dir、stable 是 sandbox 严格祖先的 clean-only 情况。它还会保守拒绝含回退后无净变化路径的历史，而不是悄悄缩小审查范围。它不是复杂脏工作区的通用合并器，更不会自动暂存、储藏、清理、解决冲突、覆盖保护文件或宣布归属。

2026-10-24 本轮只读复核仍有四类真实阻断：受保护路径导致全工作区清点不完整、历史含保护/范围外变更、稳定区修改需要保留审查、sandbox 修改需要归属审查。新适配器不能用自己生成的空 blockers 替代上述审查，也未在真实根目录上执行。

## 持久材料不等于恢复或激活授权

`managed-source-package.json` 保存完整输入；`managed-source-transaction.jsonl` 保存写前意图、退出和独立核验回执。两者永久单次使用，不自动删锁、重放或接管。

记录式执行器还必须在本次执行重新同步并核对包文件，不能把冷读当作历史同步成功的证据。文件摘要和 fsync 不证明 exFAT 断电安全，不防同权限恶意进程重写整套材料。冷读只证明记录符合结构与当前摘要；既不证明历史 fsync 曾成功，也不证明确认来源或实际源码仍保持原状。恢复和后续操作必须有独立协议。

本轮操作目录只在合成验收区域创建。真实 `managed_project_local_v1` 仍保持 `prepared_empty`，原有空布局检查没有放宽。把包接入正式命名空间之前，需要另行实现受审查的状态转换/可信上下文，不允许靠向空布局偷偷加文件绕过。

## 尚未交付的正式采用环节

- 当前脏源码的完整归属/保留范围，以及原生精确范围展示与确认。
- 正式命名空间的操作态和可信启动/执行绑定。
- 真实项目合入后的稳定树重建与封存来源证明。
- 应用所有写路径的 fencing 租约、空库初始化、持久激活/维护恢复与 LKG。
- 安全私有 provider 适配、预算和仅 `0x567-flash` 的真实模型调用。

因此不能称为“只剩用户真实使用验收”。没有读取、复制或迁移旧聊天/密钥。

## 存储边界

计划包与事务日志用固定少量文件，不复制一套依赖、源码树或运行时。包文件上限 2 MiB、既有单次日志上限 1 MiB；这是源码操作记录的边界，不是每个正式发布的空间预算。合成 Git 夹具只是工程验收，不是正式双版本的大小。F: 为 exFAT，当前采用 131072 字节分配单元估算小文件成本；按文件长度向上取整不包含目录/文件系统元数据，不能称为完整物理占用。保留既有夹具与备份，不自动清理。




## 已实现的受限 Git 元数据检查

适配器只接受受支持的、校验和正确的 Git index v2；核对普通条目、NUL 路径、padding、stage/flags，并对 TREE cache-tree 做有界结构解析。split-index 的 link、fsmonitor 的 FSMN、UNTR 及其他扩展拒绝，不把 `ls-files` 输出当成完整 index 身份。

调用 Git 前检查对象存储和相关 worktree 元数据的普通路径、链接与间接存储；Windows 另做有界 reparse 属性探测。禁用 Git replacement objects，并同时拒绝 loose/packed replacement ref。原有私有/E0 模块未放宽。

完整包复核由 recorded executor 的内部同步 guard 在适配器所有异步复核之后、实际 Git spawn 之前再次执行。guard 不能是 Promise，也不能替换固定 Git 命令。一次命令尝试即消耗适配器；失败/未知退出不能重试。成功后 stable index 必须对应合并结果树，不能错误地保留旧 stable index；sandbox index 和 stable 非交付条目才是不变项。
